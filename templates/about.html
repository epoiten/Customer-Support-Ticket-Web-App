About MedTech Support Desk

Digital4Business (D4B) Business Programming — Group Project (Option A)

Project Overview

The MedTech Support Desk is a custom web application developed to address a realistic clinical operations challenge: streamlining medical device and clinical IT fault reporting across hospital wards. Built using Python, Flask, SQLite, and Peewee ORM, the platform empowers nursing and clinical staff to log equipment issues, monitor biomedical triage progress, and update incident statuses securely.

Project Team

This project was collaboratively designed, programmed, and documented as Option A for the D4B Business Programming course by the following group members:

  • Roner Lamadrid Chichirita — Backend, Database Integration & Core Application Logic
  • Linda — UI/UX Layout, Responsive Styling & Template Architecture
  • Franz — Form Validation, JavaScript Interactivity & Testing Documentation

Technologies & Architecture

The system adheres strictly to the Option A guidelines, featuring a single relational database table (`Ticket`), lightweight server-side routing with Flask, responsive CSS styling, and client-side JavaScript interactions.
